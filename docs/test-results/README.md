## 회차별로 바꾼 것
- **1차 → 2차**: 가상 회사의 1인칭 후기와 화면 예시 숫자(8개)를 실제 성과처럼 쓴 문제 발견 → 글 종류(브랜드 사례 / 체험단 리뷰 초안) 분리, 사진 속 수치 사용 금지, 허용 태그 목록 전달, 근거 번호 본문 노출 금지
- **2차 → 3차**: "획기적·입증·보장" 같은 과장 표현과 지어낸 사용 경험 1문장 발견 → 금지어 추가, 경험은 직접 작성 자리로
- **3차 → 다시 쓰기**: 빠진 키워드 1개는 고쳤지만 이미 있던 키워드 1개가 사라짐 → 다시 쓰기 지시에 "이미 통과한 기준 유지" 조건 추가 (재시험 예정)

## 코드 점검이 잡지 못해 사람이 찾은 것
- 2차: "실제로 통화 한 건을 녹음한 후…" 같은 지어낸 사용 경험 1문장
- 3차: 샘플 화면 속 예시 내용(배송지 오기재 확인 등)을 사례처럼 씀

그래서 앱의 점검 결과 탭에는 "문장의 사실 여부는 게시 전 담당자가 한 번 더 읽어 달라"는 안내를 둡니다.
