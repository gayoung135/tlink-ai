# 티링크 AI 현장사진 홍보콘텐츠 자동생성기

> 시제: 티링크의 제품과 기술적 차별점을 AI가 분석하고, 현장 사진과 제품 정보만으로 고객의 관심을 끌 수 있는 홍보 콘텐츠를 자동 생성하는 마케팅 솔루션

현장 사진(최대 5장) + 제품 정보(`facts.csv`) + 업체 리뷰 가이드라인(`guideline.json`)을 넣으면,
AI가 **사진 분석 → 기술 차별점 매칭 → 가이드라인을 지킨 네이버 블로그 리뷰 + 인스타그램 카드뉴스**를 만들고,
**코드가 결과를 다시 검수**합니다.

## 무엇을 자동 검수하나 (할루시네이션 방지)
| 검수 | 방법 |
| :--- | :--- |
| 근거 ID | AI가 문장마다 적은 근거 `F번호`가 제품 정보에 실제로 있는지 |
| 출처 없는 숫자 | 블로그 속 모든 숫자가 제품 정보·가이드라인에 있는 숫자인지 |
| 필수 키워드 | 통화요약·콜센터 프로그램·업무자동화가 **제목과 본문**에 있는지 |
| 제목·첫 문단 키워드 | 티링크 비즈레코딩·영업사원 통화관리·휴대폰 통화녹음·인터넷전화 자동녹취 |
| 분량 | 마크다운 기호를 뺀 실제 글자 수 |
| 금지·충돌 정보 | 최상급 표현, 자료끼리 다른 **녹취 성공률(제안서 99% / 영상 95%)** 사용 여부 |
| 구성·미션 | 추천 본문 구성 5단계, 리뷰 미션 11개 반영 |
| 인스타 | 카드 5장, 글자 수, 해시태그가 가이드라인 태그 안에서 골랐는지 |
| 하단 정보 | 홈페이지·블로그·상담 문의는 **AI가 아니라 앱이 고정 문구로** 붙임 |

## 파일
| 파일 | 역할 |
| :--- | :--- |
| `app.py` | 웹앱 |
| `facts.csv` | 제품 정보 30건 (제안서·매뉴얼·홈페이지에서 확인된 문장만, 출처 표기) |
| `guideline.json` | 티링크 리뷰 가이드라인 (키워드·태그·미션·추천 구성·하단 정보) |
| `samples/` | 시연용 화면 5장 (제안서에 실린 고객정보 흐림 처리된 화면) |
| `requirements.txt` | 패키지 목록 |

> 다른 업체·제품은 `guideline.json`과 `facts.csv`만 바꿔서 사이드바에 올리면 그대로 쓸 수 있습니다.

## 1. 무료 URL 만들기 (PC에 파이썬 설치 필요 없음)
**Streamlit Community Cloud**를 사용합니다. 무료이고, 서버 관리가 필요 없으며, `https://이름.streamlit.app` 주소가 생깁니다.

### ① GitHub에 올리기
1. github.com 가입 → 오른쪽 위 **+** → **New repository**
2. 이름 `tlink-ai`, **Public** 선택 → **Create repository**
3. **uploading an existing file** 클릭 → 압축 푼 `tlink-ai` 폴더 **안의 파일과 `samples` 폴더**를 모두 끌어다 놓기 → **Commit changes**
   - `app.py`가 저장소 맨 위(루트)에 보여야 합니다.
   - API 키가 든 파일은 절대 올리지 않습니다.

### ② Gemini API 키 받기
- aistudio.google.com 접속 → **Get API key** → **Create API key** → 키 복사

### ③ 배포
1. share.streamlit.io → **Continue with GitHub**로 로그인
2. **Create app** → **Deploy a public app from GitHub**
3. Repository `본인아이디/tlink-ai`, Branch `main`, Main file path `app.py`
4. App URL에 원하는 이름 입력 (예: `tlink-ai-content`)
5. **Advanced settings** → **Secrets** 칸에 아래를 붙여넣기:
   ```
   GEMINI_API_KEY = "복사한_키"
   GEMINI_MODEL = "gemini-2.5-flash"
   ```
6. **Deploy** → 1~3분 뒤 `https://tlink-ai-content.streamlit.app` 같은 주소가 열립니다.

### 알아둘 것
- 12시간 동안 아무도 안 들어오면 앱이 잠듭니다. 들어가서 **Yes, get this app back up!** 버튼을 누르면 1분 안에 깨어납니다. **심사 전에 한 번 열어 두세요.**
- 방문자가 생성 버튼을 누를 때마다 내 무료 API 사용량이 쓰입니다. 무료 한도를 넘으면 잠시 뒤 다시 시도하라는 안내가 나옵니다.
- 모델명이 안 맞는다는 오류가 나면 AI Studio에서 무료로 쓸 수 있는 모델명을 확인해 Secrets의 `GEMINI_MODEL`을 바꾸세요.
- 코드를 고치면 GitHub에서 파일을 다시 올리기만 하면 자동 반영됩니다.

## 2. (선택) 내 PC에서 실행
파이썬 3.10 이상이 있다면:
```

python -m streamlit run app.py
```
