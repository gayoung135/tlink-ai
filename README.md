# 티링크 AI 현장사진 홍보콘텐츠 자동생성기

현장 시공 사진 한 장과 제품 정보 시트만으로, AI가 설치 환경을 분석하고 티링크 제품의 기술 차별점을 연결해 블로그·인스타그램 홍보 초안과 검수 체크리스트를 만들어 주는 MVP입니다.

## 흐름
사진 업로드 → Gemini 사진 분석 → 제품 정보 시트에서 차별점 매칭 → 채널별 콘텐츠 생성 → **코드가 직접 검증**(근거 문장 원문 대조, 글자 수, 카드 장수, `[확인 필요]` 개수)

## 파일
| 파일 | 역할 |
| :--- | :--- |
| `app.py` | Streamlit 웹앱 |
| `products.csv` | 제품 정보 시트 (AI는 이 내용만 근거로 씀) |
| `requirements.txt` | 필요한 패키지 |

---

## 1. 실행 방법 (VS Code)
1. Python 3.10 이상 설치 확인: 터미널에서 `python --version`
2. 이 폴더를 VS Code로 열고 터미널(`Ctrl + ~`)에서:
   ```
   pip install -r requirements.txt
   ```
3. Gemini API 키 발급: Google AI Studio(aistudio.google.com) → **Get API key** → 키 복사
4. 실행:
   ```
   streamlit run app.py
   ```
5. 브라우저가 열리면 왼쪽에 API 키를 붙여넣기
   - 모델명 칸은 AI Studio에서 무료로 쓸 수 있는 모델명으로 바꾸기
6. 사진 업로드 → 설치 제품 선택 → **콘텐츠 생성**

> API 키는 코드나 GitHub에 절대 올리지 말 것. 화면 녹화할 때도 키 입력 장면은 찍지 않기 (미리 입력해 두거나 환경변수 `GEMINI_API_KEY` 사용).

## 2. 제품 정보 시트 채우기
- `products.csv`는 공개 자료로 확인된 내용만 넣었고, 나머지는 `[확인 필요]`입니다.
- 티링크 담당자 자료로 확인한 내용만 추가하세요. 시트에 없는 내용은 AI가 쓰지 못하게 설계했습니다.
- 엑셀이나 구글 시트로 편집한 뒤 **CSV(UTF-8)**로 저장하면 됩니다.

## 3. 시연 전 테스트 (프로젝트 설명에 넣을 숫자 만들기)
현장 사진 **5~10장**으로 돌려 보고 아래 표를 채우세요. 이 숫자가 2단계 [프로젝트 설명]의 근거가 됩니다.

| # | 사진 | 사진 분석 맞음? | 근거 확인(✅/전체) | 글자 수 통과? | 걸린 시간(초) |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 1 | | | | | |
| 2 | | | | | |

- 사진은 **시험용**으로만 쓰고, 고객사 상호·얼굴이 보이면 가리거나 다른 사진으로 바꾸기
- 앱에 🔒 개인정보 경고가 뜨는지도 함께 기록

**녹화 방법 (Windows 기준)**
- `Win + G` (Xbox Game Bar) → 녹화 버튼, 또는 OBS Studio 사용
- 브라우저 창을 1920×1080 가로로 맞추고, 글씨가 작으면 `Ctrl + +`로 확대
- 편집은 Clipchamp(윈도우 기본 앱)로 자르기와 자막 정도만 하면 충분

**유튜브 업로드**
- 공개 상태: 대회 안내대로 **공개**
- 가로 영상이어야 하고, 쇼츠로 올리면 안 됨 (세로 영상이나 60초 이하 영상이면 쇼츠로 분류될 수 있음)

## 5. 2단계 [프로젝트 설명] 템플릿
> 빈칸은 3번 테스트에서 직접 잰 숫자만 넣기.

1단계 계획대로 현장 사진 업로드 → Gemini 사진 분석 → 제품 정보 시트 기반 차별점 매칭 → 블로그·인스타그램 초안과 검수 체크리스트 생성까지 완성했습니다. 시험용 현장 사진 __장으로 테스트해 보니 사진 분석은 __장이 맞았고, AI가 제시한 차별점 근거 __건 중 __건이 시트 원문과 일치했습니다(일치하지 않은 __건은 앱이 ⚠️로 걸러냄). 사진 한 장당 생성까지 약 __초가 걸렸습니다. ____에게 써 보게 했더니 "____"라는 반응이었습니다. 아직 못 한 것: SNS 자동 게시와 사진 속 개인정보 자동 가림은 다음 버전에서 만듭니다.
